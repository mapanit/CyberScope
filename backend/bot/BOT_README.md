# CyberScope Telegram Bot

Переделанный Telegram бот для запуска сканирований безопасности и управления отчетами.

## Новые возможности

### ✨ Основные функции

1. **🔍 Запуск сканирования**
   - Интерактивный ввод target (домен или URL)
   - Выбор инструментов сканирования
   - Уведомление о завершении сканирования
   - Отслеживание статуса в реальном времени

2. **📊 Управление отчетами**
   - Просмотр списка доступных отчетов
   - Скачивание отчетов в формате JSON
   - Скачивание отчетов в формате TXT
   - Быстрый доступ к последним отчетам

3. **⚙️ Доступные инструменты сканирования**
   - **wappalyzer** - определение технологий и фреймворков
   - **osint** - поиск поддоменов и информацию о домене
   - **web** - веб-разведка (URL и директории)
   - **retire** - поиск уязвимостей в JavaScript библиотеках

## Установка и конфигурация

### 1. Создание .env файла

Скопируйте [.env.example](.env.example) в `.env` и заполните значения:

```bash
cd backend/bot
cp .env.example .env
```

Отредактируйте `.env`:
```
BOT_TOKEN=your_telegram_bot_token_here
API_BASE_URL=http://127.0.0.1:8000/api
```

### 2. Установка зависимостей

```bash
cd backend
pip install -r requirements.txt
```

### 3. Запуск бота

```bash
python bot/bot.py
```

## Использование

### Команды бота

| Команда | Описание |
|---------|---------|
| `/start` | Главное меню |
| `/help` | Справка и инструкции |
| `/scan` | Быстрое сканирование |
| `/reports` | Список отчетов |
| `/cancel` | Отмена текущей операции |

### Сценарий использования

1. **Запуск сканирования:**
   ```
   /start → 🔍 Начать сканирование
   ↓
   Введите target (example.com или http://localhost:5000)
   ↓
   Выберите инструменты (можно несколько)
   ↓
   Подтвердите запуск
   ↓
   Ожидание завершения...
   ↓
   ✅ Сканирование завершено!
   ```

2. **Скачивание отчета:**
   ```
   После завершения сканирования → Нажмите кнопку "📄 Скачать JSON" или "📝 Скачать TXT"
   ↓
   Отчет будет отправлен в чат
   ```

3. **Просмотр старых отчетов:**
   ```
   /start → 📊 Мои отчеты
   ↓
   Выберите отчет для скачивания
   ```

## Интеграция с API

Бот взаимодействует со следующими API endpoints (определены в [routes](../routes/)):

### Сканирование
- `GET /api/run-selected-tools` - запуск выбранных инструментов
- `GET /api/wappalyzer` - анализ технологий
- `GET /api/osint` - OSINT сканирование
- `GET /api/web` - веб-разведка
- `GET /api/retire` - сканирование JS библиотек

### Управление отчетами
- `GET /api/combined-reports` - список объединённых отчетов
- `GET /api/download-combined-report` - скачивание отчета
- `GET /api/txt-reports` - список TXT отчетов
- `GET /api/download-txt-report` - скачивание TXT отчета

## Структура кода

```python
# Основные компоненты:

1. ScanForm - FSM состояния для процесса сканирования
   - target - ввод цели сканирования
   - tools - выбор инструментов
   - allow_internal - разрешить внутренние адреса
   - scanning - процесс идет

2. Функции:
   - run_scan() - асинхронное запуск сканирования
   - download_report_file() - скачивание отчета
   - process_*() - обработчики callback'ов

3. API интеграция:
   - aiohttp для асинхронных HTTP запросов
   - Таймауты и обработка ошибок
```

- ✅ Информативные сообщения об ошибках
- ✅ Логирование всех операций

## Примечания

- Бот работает асинхронно, не блокирует интерфейс
- Текущие сканирования отслеживаются по User ID и времени
- Все отчеты скачиваются напрямую из API
- Поддерживается отмена операций командой `/cancel`
