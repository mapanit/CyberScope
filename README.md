🌐 CyberScope - Комплексный анализ веб-ресурсов

CyberScope - это мощная веб-платформа для комплексного анализа и разведки веб-сайтов. Автоматизируйте процесс сканирования на уязвимости, обнаружения скрытых каталогов и сбора разведывательной информации в одном интерфейсе.

Инструменты для пентеста взяты готовые из github и также есть кастомный сканер

🔍 Что умеет CyberScope?

Безопасность и уязвимости

    Сканирование открытых портов и сервисов

    Обнаружение потенциально уязвимых служб

    Проверка конфигурации безопасности

    Анализ заголовков безопасности HTTP

Разведка и обнаружение

    Поиск скрытых каталогов и файлов

    Обнаружение поддоменов

    Анализ стека технологий (CMS, фреймворки, библиотеки)

    Сбор WHOIS информации

    Определение IP-адресов и геолокации


# Настройка 

Установка необходимых инструментов go и python

chmod -x install-tools.sh
/install-tools.sh

# Запуск сервера разработки

cd ./backend
python -m venv venv
source venv/bin/activate
pip3 install -r requirements.txt

uvicorn server:app --reload

# Запуск клиента
cd frontend
npm i
npm start

🎯 Для кого предназначен CyberScope?

    Пентестеры - для автоматизации рутинных задач разведки

    Администраторы - для мониторинга безопасности собственных ресурсов

    Разработчики - для проверки безопасности своих приложений

    Исследователи - для сбора информации о веб-ресурсах

🔒 Ответственное использование

CyberScope предназначен исключительно для:

    Тестирования собственных веб-ресурсов

    Проведения легальных пентестов с разрешения владельца

    Исследовательских и образовательных целей

CyberScope - ваш надежный партнер в обеспечении кибербезопасности и проведении комплексного анализа веб-ресурсов.
